# Narrative Trading Report Layer

This layer turns daily signal outputs into a professional trading intelligence report.

It does not replace the model or the signal policy. It reads the outputs generated by `run_daily_signal.py` and creates:

- `narrative_trading_report.md`
- `narrative_signal_cards.csv`
- `narrative_signal_cards.json`

## Command

```bash
python3 workflows/build_narrative_trade_report.py \
  --root . \
  --signal-dir signals/daily/signal_20_may_2026 \
  --policy configs/narrative_policy.json
```

Or use target date lookup:

```bash
python3 workflows/build_narrative_trade_report.py \
  --root . \
  --target-date 2026-05-20
```

## Design principle

The report is conditional, not deterministic. It explains:

- market context,
- price structure,
- momentum and volatility,
- liquidity behaviour,
- broker-flow evidence,
- entry conditions,
- invalidation logic,
- exit/take-profit logic,
- no-trade conditions.

A signal is not treated as an automatic buy. It is a thesis that remains valid only while the underlying structure and behaviour remain aligned.

## Output interpretation

`signals_main.csv` and `execution_shortlist.csv` remain execution-oriented outputs. The narrative report adds decision context and should be used for discretionary review, paper trading, and operational intelligence.
